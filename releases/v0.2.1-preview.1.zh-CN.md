# v0.2.1-preview.1 — WinUI Windows x64 便携预览

此修订准备**面向 Windows 11 24H2 x64 的未签名预发布**，此次修改没有创建版本标签。实际发布时，公开附件继续使用现有便携 ZIP 契约，包含完整 WinUI 文件和独立 Rust Runner。

## 变更

- 增加每用户 Inno 安装器及独立 C# NativeAOT Manager 启动器／部署组件，单独提供本地和手动工作流安装器预览。
- 增加共享／独占安装锁、清单绑定的版本暂存及显式修复／回退／仅卸载 Manager，保留配置、稳定 Runner 和游戏。
- 增加协调的 Windows PE 元数据、签名政策检查与签后 Runner 清单准备。Runner 资源改变字节，因此版本递增至 0.2.1。
- 增加使用注入测试信任的内部更新认证底层，没有启用生产更新地址或自动更新器。
- 增加完整英语／简体中文部署提示、安装／恢复说明和签名政策。

## 已知限制

- 当前未签名，仍为预览。SignPath Foundation 申请／批准和生产签名未接入；干净 Windows 11 客户端、原生向导／Explorer、任务栏固定、更多故障恢复和正常防护下下载验收仍待完成。
- 安装器使用隔离目录和真实安装进程测试，人工下一版本夹具只验证部署行为，不代表真实下一版本二进制或签名证据。
- 公开标签附件暂不包含安装器。已安装 Manager 使用人工恢复，未知文件和隔离的半复制文件保留；未实现自动清理旧版本和无人值守启动回退。
- 更新界面、可信产物下载和确认后安装，等待已签名交付门槛，尚未启用／实现。
- Steam 启动项仍手动复制，游戏／启动器／Overlay／成就证据限于已记录场景。

## 安装、更新与恢复

从同一发布下载 `SteamWrapper-v0.2.1-preview.1-win-x64.zip` 与 `SHA256SUMS`，对照 SHA-256，完整解压后从普通文件资源管理器打开 `SteamWrapper.Manager.exe`。保留运行时、本地化与 Runner 文件；使用完整下载包不需要开发 SDK。

关闭 Manager，将便携更新解压到新目录。稳定 Runner 安装仍由 Manager 的独立操作负责，拒绝未知或同版本不同字节，保留较新兼容版本。遇到 Runner／游戏占用，正常结束后再试。配置、偏好与 Runner 留在 `%LOCALAPPDATA%\SteamWrapper\`，Steam 只引用稳定的 `bin\SteamWrapperRunner.exe`。

详见[安装](https://yangyus8.top/SteamWrapper/zh-cn/guides/installation/)、[安装器预览与恢复](https://yangyus8.top/SteamWrapper/zh-cn/guides/installer-preview/)和[代码签名政策](https://yangyus8.top/SteamWrapper/zh-cn/project/design/code-signing/)。校验和确认附件一致性，不认证发布者。
