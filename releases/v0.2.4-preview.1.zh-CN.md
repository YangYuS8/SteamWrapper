# SteamWrapper v0.2.4-preview.1

这是支持原生 x64 电脑上 Windows 11 24H2 或更高版本的**未签名 Windows 技术预览**，修复上一预览中新发现的编辑器问题。干净客户端验收和生产签名仍待完成，不是稳定版。

- 加载配置、通过切换配置放弃草稿，或将字段恢复原值后，不再误报“未保存的修改”。编辑器比较完整表单与加载／成功保存后的内容。真正未保存的修改仍需在离开前作出选择，取消导航会保留草稿。
- 实际窗口回归覆盖添加本地发现的游戏、手动 AppID 校验与保存、重复拒绝、重启持久化、草稿保留及限定窗口的键盘消息。既有保存、语言及原始参数文本行为仍有覆盖。这些检查不证明硬件键盘、输入法、缩放或剪贴板验收通过。
- 新增真实子进程测试覆盖六个卸载中断检查点、操作系统锁释放、部分删除后的恢复、未知／修改字节保留和重装。载荷使用受控夹具，不模拟整机断电，也不替代真实 Inno 验收。
- 没有保存语言选择时，Manager 与启动器恢复提示跟随已支持的系统界面语言，不支持时使用英语。手动选择优先，并保留游戏名称、路径和参数。

使用 Setup 为当前用户安装 Manager，或解压**完整**便携 ZIP，在文件资源管理器中打开 `SteamWrapper.Manager.exe`。安装／卸载保留配置、偏好、稳定 Runner、备份、日志与缓存封面，不修改 Steam／游戏文件或启动选项。测试前阅读[安装与恢复指南](https://yangyus8.top/SteamWrapper/zh-cn/guides/installer-preview/)。每个变化的可安装载荷需要新的数字版本，已公开版本保持不可变。

发行包含七份附件，`SHA256SUMS` 覆盖其余六份。第 2 版安装器描述保留原有第 1 版便携描述。两种包均提供原始依赖许可证、`THIRD_PARTY_NOTICES.md` 和 `LICENSES/index.json`。常规 main／PR CI 继续测试与编译，版本标签构建并发布 Setup 与 ZIP。

已知限制包括无开发工具的干净 Windows、更广原生／玩家验收、旧版本清理、注册表／快捷方式故障恢复及真实已签名下载。尚无自动更新或自动应用／恢复 Steam 启动选项。封面保持本地优先，可选官方 CDN 补图默认关闭。

[代码签名政策（Code signing policy）](https://yangyus8.top/SteamWrapper/zh-cn/project/design/code-signing/)：SignPath Foundation 申请尚未提交或获批，此预览不提供签名证书或认证更新源。Microsoft 运行时依赖及拟定 Inno 签名链需服务方审核。默认操作不上传配置、游戏文件或游戏库内容。GitHub 为二进制发行渠道，CNB 二进制仅在配置镜像且通过下载核验后公告。
