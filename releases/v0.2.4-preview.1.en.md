# SteamWrapper v0.2.4-preview.1

This is an **unsigned Windows technical preview** for Windows 11 24H2 or later on native x64 PCs. It fixes an editor issue discovered in the previous preview. Clean-client acceptance and production signing remain open; this is not a stable release.

- Loading a profile, discarding a draft by switching profiles, or restoring the original field values no longer produces a false “Unsaved changes” prompt. The editor compares its complete form with the loaded or successfully saved values. Genuine unsaved changes still require a choice before leaving, and cancelling navigation preserves the draft.
- Actual-window regressions cover adding a locally discovered game, manual AppID validation and saving, duplicate rejection, restart persistence, draft retention and scoped window keyboard messages. Existing save, language and original argument-text behavior remain covered. These checks do not establish hardware keyboard, IME, scaling or clipboard acceptance.
- Additional real child-process tests cover six uninstall interruption checkpoints, released OS locks, recovery after partial deletion, preserved unknown/modified bytes and reinstallation. These use controlled fixture payloads; they do not simulate machine power loss or replace real Inno acceptance.
- With no saved language choice, Manager and launcher recovery messages follow the supported system UI language. Unsupported languages use English. Manual choices take priority and preserve game names, paths and arguments.

Use the Setup for a per-user Manager installation, or extract the **entire** portable ZIP and open `SteamWrapper.Manager.exe` in File Explorer. Installation/uninstallation preserves profiles, preferences, the stable Runner, backups, logs and cached covers. It does not change Steam/game files or Launch Options. Read the [installation and recovery guide](https://yangyus8.top/SteamWrapper/guides/installer-preview/) before testing. Every changed installable payload requires a new numeric version; existing public versions remain immutable.

The release provides seven assets, with `SHA256SUMS` covering the other six. The schema-2 installer descriptor includes the unchanged schema-1 portable descriptor. Both packages include original dependency licenses, `THIRD_PARTY_NOTICES.md` and `LICENSES/index.json`. Ordinary main/PR CI continues to test and compile; version tags build and publish Setup and ZIP.

Known limits include clean Windows without developer tools, broader native/player acceptance, version pruning, registry/shortcut failure recovery and actual signed-download acceptance. Automatic updates and automatic Steam Launch Options apply/restore are unavailable. Covers remain local-first, with optional official CDN fallback disabled by default.

[Code signing policy](https://yangyus8.top/SteamWrapper/project/design/code-signing/): the SignPath Foundation application has not been submitted or approved. No signing certificate or authenticated update feed is supplied. Microsoft runtime dependencies and the proposed Inno signing chain require provider review. Default operation does not upload profiles, game files or library contents. GitHub is the binary release channel; CNB binaries are advertised only after a configured mirror passes download verification.
