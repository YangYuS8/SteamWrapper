# SteamWrapper v0.2.6-preview.1

This preview fixes Runner startup on Windows computers without the Visual C++ redistributable and fits the initial Manager window to the display's actual scale and usable area.

- The Windows Runner includes its C/C++ runtime, so players do not need a separate Visual C++ runtime installation.
- Manager starts within the display's usable area at 100%, 150% and 200% scaling. Later resizing remains under the player's control.
- Updates and repairs remove verified obsolete Manager copies after a successful startup, retaining the current and previous versions for rollback. Unknown or busy files are preserved. Repeated updates without opening Manager stop safely before retained copies can prevent uninstalling.
- Stable and preview update channels are separate. A newer stable version can reach preview installations through **Check for updates**. Downloads use official GitHub releases or the verified CNB mirror; automatic checks remain off by default.
- Installation supports a custom folder, Start menu and desktop shortcuts, and opening Manager when finished. Uninstall preserves player data by default, with seven independent optional cleanup choices.
- Game profiles, stable Runner data, Steam Launch Options, games and saves are preserved during Manager updates. No Manager, Runner or game process is force-closed.

The local candidate passed an 18-step installation/repair/upgrade/uninstall/reinstall test and a separate 10-step portable test in fresh Windows 11 24H2 Sandboxes without additional SDKs or runtimes. Native configuration, English/Chinese resources, Chinese IME composition and the three display scales also passed. The clean guest tests used the Sandbox administrator account; genuine standard-account acceptance and the public download-to-install update flow are still being completed. This is a preview, not the first stable WinUI release.

Supported package: Windows 11 24H2 x64. Extract the entire portable ZIP before running Manager. Installation is per user. Steam Launch Options are still copied manually; general one-click apply/restore is not implemented. Manager only configures games; daily Steam launches use the independent Runner.

Update metadata verifies the exact installer with the project's signing key. Setup and the project's Windows programs do not have Windows Authenticode signatures; Windows can show trust prompts or enforce local restrictions. Verify downloads with the published checksums and keep Windows protection enabled.
