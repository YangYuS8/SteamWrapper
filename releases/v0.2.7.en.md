# SteamWrapper v0.2.7

The first stable Windows release of the WinUI 3 Manager. Configure a game once, copy its Launch Options into Steam, and launch it normally from Steam afterward. Daily launches use the independent Runner and do not open Manager.

- Setup installs for the current user, with a choice of installation folder, Start menu and desktop shortcuts, and opening Manager when finished. No developer SDK or separate runtime installation is required.
- English and Simplified Chinese are available throughout the application. With no saved choice, the interface follows a supported Windows UI language and otherwise uses English.
- Covers work offline by default, using Steam's local artwork. An optional setting downloads missing covers from the official Steam CDN; unavailable images retain a friendly placeholder.
- Manager supports manual update checks using project-signed metadata and exact installer verification. GitHub and the verified CNB mirror provide the same release. Automatic checks are off by default; installation waits for Manager to close normally.
- Updates and repairs preserve player data and retain the previous Manager version for recovery. Uninstall preserves configuration and the stable Runner by default, with seven independent optional cleanup choices.
- The Runner includes its C/C++ runtime. Manager explains how to update a recognized older Runner by saving a game profile, without replacing it merely while checking its version.
- The initial window respects the display's actual scale and usable area. Stable packages display the Windows label; development and prerelease builds retain their preview label.

Windows package: x64, minimum Windows 11 24H2. Clean-client acceptance uses Windows 11 24H2. Open Manager in the Windows account you normally use with Steam; running it as a different user in the current desktop is outside this release's support scope. Windows 10, ARM64, Linux/SteamOS Manager and general one-click Steam Launch Options apply/restore are also outside this release. Steam Launch Options still require manual copying. Portable users must extract the complete ZIP and update with a new complete ZIP.

Setup and the project's Windows programs do not have Windows Authenticode signatures. Windows can show trust prompts or enforce local restrictions. Project-signed update metadata authenticates the installer for in-app updates; it does not supply a Windows publisher certificate. Use the official downloads and published checksums, and keep Windows protection enabled.

SteamWrapper does not modify game binaries or saves and does not inject DLLs. It cannot guarantee achievements for third-party translations; that depends on the game's own Steam integration.
