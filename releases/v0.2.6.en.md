# SteamWrapper v0.2.6

This version fixes Runner startup on Windows computers without the Visual C++ redistributable, limits old Manager copies accumulating across repeated updates, and prepares separate stable and preview update channels.

- The Windows Runner includes its required C/C++ runtime internally, so players do not need a separate Visual C++ runtime installation to start it.
- After the installed Manager starts successfully, the next update or repair removes verified obsolete program copies while keeping the current and previous versions for rollback. Unknown or busy files are preserved; interrupted cleanup keeps recoverable files for diagnosis.
- Repeated updates without starting Manager now stop safely before retained copies can prevent uninstalling. Open the installed Manager, close it normally, then retry. The new installer can also handle installations that already accumulated more than 32 versions, within its safety limits.
- A newer stable release can reach existing preview installations through **Check for updates**. Stable installations use the stable feed; previews remain in the preview feed until they install a stable version. Downloads use official GitHub releases or an advertised, verified CNB mirror. Automatic checks remain optional and off by default.
- Updates preserve game profiles, the stable Runner, Steam Launch Options, games and saves. No Manager, Runner or game process is force-closed.
- Update information authenticates the exact installer with the project's signing key. Setup and the project's Windows programs remain unsigned by Windows Authenticode, so Windows may display trust prompts or apply local restrictions.

These notes are prepared for v0.2.6; the latest public version remains v0.2.5-preview.1. This local candidate passed first installation, native configuration, repair, uninstall with data preserved, and reinstall to a Chinese folder in a fresh offline Windows 11 Sandbox without extra SDKs or runtimes. It used the Sandbox administrator account. Public release, clean version-upgrade/portable checks, standard-user, multiple display scales and Chinese IME acceptance remain pending; this scoped pass does not establish those full checks.
