# SteamWrapper v0.2.6

本版修复未安装 Visual C++ 运行库的 Windows 电脑上 Runner 无法启动的问题，限制反复更新后旧管理器副本不断积累，并准备独立的稳定版与预览版更新通道。

- Windows Runner 内含所需的 C/C++ 运行库，玩家无需额外安装 Visual C++ 运行库即可启动 Runner。
- 已安装的管理器成功启动后，下一次更新或修复会删除经过验证的过期程序副本，保留当前版本和上一版本以便回退。未知或占用的文件会保留；清理中断时，会保留可恢复文件供诊断。
- 连续更新却没有启动管理器时，现在会在保留副本导致无法卸载之前安全停止。打开已安装的管理器、正常关闭后再重试即可。对于已经积累超过 32 个版本的安装，新安装器也能在安全限制内处理。
- 新的稳定版本可以通过**检查更新**提供给现有预览版用户。稳定版使用稳定更新源；预览版在安装稳定版本前继续使用预览更新源。下载来自官方 GitHub 发布页或已公布且经过验证的 CNB 镜像。自动检查仍然可选且默认关闭。
- 更新保留游戏配置、稳定路径中的 Runner、Steam 启动选项、游戏及存档，不会强制结束管理器、Runner 或游戏进程。
- 更新信息通过项目自己的签名密钥验证对应安装包。Setup 和项目自有 Windows 程序仍未进行 Windows Authenticode 代码签名，系统可能显示信任提示或应用本机限制。

这些说明为 v0.2.6 预先准备，最新公开版本仍为 v0.2.5-preview.1。本地候选在无需额外 SDK 或运行库的全新离线 Windows 11 Sandbox 中，通过首次安装、原生配置、修复、卸载保留数据及中文目录重装，使用的是 Sandbox 管理员账户。公开发布、干净版本升级／便携版、普通用户、多种显示缩放和中文输入法验收仍未完成；这个限定范围的通过结果不代表这些完整检查通过。
