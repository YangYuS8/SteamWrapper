# v0.2.1-preview.1 — WinUI Windows x64 portable preview

This revision prepares an **unsigned prerelease for Windows 11 24H2 x64**. The tag has not been created by this change. If released, its public assets follow the existing portable ZIP contract, with the complete WinUI layout and independent Rust Runner.

## Changes

- Added the per-user Inno installer and independent C# NativeAOT Manager launcher/deployment component, available separately as a local/manual-workflow installer preview.
- Added shared/exclusive installation leases, manifest-bound version staging and explicit repair/rollback/Manager-only uninstall. Setup preserves profiles, stable Runner and games.
- Added coordinated Windows PE metadata and signing-policy/post-sign Runner-manifest preparation. Versions advance to 0.2.1 because the Runner resource changes its bytes.
- Added internal authenticated update-validation groundwork using injected test trust. No production update endpoint or automatic updater is enabled.
- Added matching English/Simplified Chinese deployment messages, installation/recovery instructions and signing policy.

## Known limits

- This is unsigned and remains a preview. SignPath Foundation application/approval and production signing are not connected. Clean Windows 11 client, native wizard/Explorer, taskbar pins, broader failure recovery and normal-protection download acceptance remain open.
- Installer tests use disposable roots and real setup processes. Synthetic next-version fixtures establish deployment behavior only, not a real next-version binary build or signing evidence.
- Public tag assets do not include setup yet. Installed Manager recovery is manual; unknown files and quarantined partial stages are retained. Automatic old-version cleanup and unattended startup rollback are not implemented.
- Update UI, authenticated artifact download and confirmed installation remain disabled/unimplemented pending the signed-delivery gates.
- Steam Launch Options are copied manually. Game/launcher/Overlay/achievement evidence remains limited to recorded scenarios.

## Install, update and recover

Download `SteamWrapper-v0.2.1-preview.1-win-x64.zip` and `SHA256SUMS` from the same release, compare SHA-256, extract the entire ZIP and open `SteamWrapper.Manager.exe` through ordinary File Explorer. Keep runtime, localized and Runner files together. No developer SDK is needed to use the complete downloaded application.

Extract portable updates into a new directory with Manager closed. Stable Runner installation remains a separate Manager action: it rejects unknown or same-version changed binaries and preserves compatible newer versions. Let any busy Runner/game finish normally before retrying. Profiles/settings/Runner remain under `%LOCALAPPDATA%\SteamWrapper\`; Steam references only stable `bin\SteamWrapperRunner.exe`.

Read [installation](https://yangyus8.top/SteamWrapper/guides/installation/), [installer preview and recovery](https://yangyus8.top/SteamWrapper/guides/installer-preview/) and [code-signing policy](https://yangyus8.top/SteamWrapper/project/design/code-signing/). Checksums establish asset consistency, not publisher identity.
