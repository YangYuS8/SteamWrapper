# SteamWrapper v0.2.3-preview.1

This is an **unsigned Windows technical preview**, provided for testing and the pending SignPath Foundation application. It targets Windows 11 24H2 or later on native x64 PCs. Clean-client acceptance and production signing remain open; it is not a stable release.

- With no saved language choice, Manager and its independent launcher's recovery messages follow the supported system UI language. Simplified Chinese systems use Chinese; unsupported languages use English. Manual choices take priority, without translating game names, paths, arguments or diagnostics.
- Installation admission accounts for the complete staged payload, manifest, launcher copy and transaction files. Isolated process-stop tests cover durable recovery and lease release without terminating an existing Manager or game.
- Version tags publish an explicit schema-2 installer and portable package. The legacy schema-1 portable descriptor is retained separately. `SHA256SUMS` lists the other six assets; download verification checks the complete seven-asset set. Ordinary main/PR CI still only tests and compiles the application.
- Both packages include `THIRD_PARTY_NOTICES.md`, the hash inventory in `LICENSES/index.json`, and the original dependency license and notice files. Upstream signatures and license terms are preserved. Microsoft runtime/package terms still require Foundation review of any applicable System Libraries exception; the project's Apache-2.0 license does not replace dependency licenses.

Use the Setup for a per-user Manager installation, or extract the **entire** portable ZIP and open `SteamWrapper.Manager.exe` in File Explorer. Installation/uninstallation preserves profiles, preferences, stable Runner, backups, logs and cached covers. Steam/game files and Launch Options are not changed. Read the [installation and recovery guide](https://yangyus8.top/SteamWrapper/guides/installer-preview/) before trying the preview. Changed payloads require a new numeric version; do not substitute another build of the same version.

Known limits: clean Windows without developer tools, full keyboard/IME/scaling/clipboard acceptance, version pruning, registry/shortcut failure recovery and actual signed-download acceptance remain unverified. Automatic updates and automatic Steam Launch Options apply/restore are not available. Missing artwork retains a placeholder; official CDN fallback remains an explicit, default-off preference.

[Code signing policy](https://yangyus8.top/SteamWrapper/project/design/code-signing/): Foundation application and approval are pending. No signing certificate or authenticated update feed is supplied with this preview. Default operation does not upload profiles, game files or library contents. Optional official cover requests require user consent. GitHub is the binary release channel; CNB binaries are available only after its configured mirror passes download verification.
