# SteamWrapper v0.2.6-preview.1

本预览版修复未安装 Visual C++ 运行库的 Windows 电脑上 Runner 无法启动的问题，并根据实际显示缩放和可用区域设置管理器的初始窗口。

- Windows Runner 内含所需的 C/C++ 运行库，玩家无需另行安装 Visual C++ 运行库。
- 已安装较旧且可识别的 Runner 时，管理器会提示保存一个游戏配置即可更新。仅检查版本不会替换现有 Runner，未知或占用的文件也不会被覆盖。
- 管理器在 100%、150% 和 200% 缩放下，初始窗口均位于屏幕可用区域内。之后的窗口大小由玩家自行调整。
- 管理器成功启动后，更新和修复会清理经过验证的过期副本，保留当前及上一版本供回退。未知或占用的文件会保留；连续更新却未打开管理器时，会在保留副本妨碍卸载前安全停止。
- 稳定版和预览版使用独立更新通道。预览版可以通过**检查更新**获取较新的稳定版本。下载来自官方 GitHub 发布页或经过验证的 CNB 镜像；自动检查仍默认关闭。
- 安装时可选择目录、开始菜单及桌面快捷方式，并选择完成后打开管理器。卸载默认保留玩家数据，另提供七项独立的可选清理选项。
- 更新管理器会保留游戏配置、稳定路径的 Runner 数据、Steam 启动选项、游戏及存档，不会强制结束管理器、Runner 或游戏进程。

本地候选已在无需额外 SDK 或运行库的全新 Windows 11 24H2 Sandbox 中，通过 18 步安装／修复／升级／卸载／重装测试，以及独立的 10 步便携版测试。原生配置、英中资源、中文输入法组合输入和三种显示缩放也已通过。干净系统测试使用 Sandbox 管理员账户；真正普通账户验收和公开下载到安装的更新闭环仍在完成。本版是预览版，还不是首个 WinUI 稳定版。

支持的发行平台为 Windows 11 24H2 x64。便携版需完整解压后运行；安装版按当前用户安装。Steam 启动选项仍需手动复制，通用的一键应用／恢复尚未实现。管理器只负责配置游戏，日常 Steam 启动由独立 Runner 完成。

更新信息通过项目自己的签名密钥验证对应安装包。Setup 和项目自有 Windows 程序未进行 Windows Authenticode 代码签名，系统可能显示信任提示或应用本机限制。请使用发布的校验和核验下载，并保持 Windows 防护开启。
