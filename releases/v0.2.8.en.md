# v0.2.8

## Changes

- Added **Revert edits**, **Restore Steam launch** and **Remove configuration** to the game editor. Restoration keeps the configuration; removal keeps a backup and never deletes games or saves.
- Game lists now use Steam's locally cached official title for the selected interface language. Custom names and unsaved edits remain intact; no store connection is needed.
- Simplified the application title to **SteamWrapper**, with the version shown separately.
- Public downloads are now just the installer, portable ZIP and checksums. GitHub release notes are English; CNB notes are Simplified Chinese.
- Actions skip unrelated checks, reuse pinned tool/dependency caches and run each Rust process regression once. Version releases retain their full checks.

## Installation and updates

Use Setup for installation-folder and shortcut choices, or extract the complete portable ZIP. Supported scope remains Windows 11 24H2 x64 and the Windows account you use with Steam.

Exit Steam normally before restoring its launch command or removing a configuration. Only exact generated commands are cleared; custom options and unknown earlier arguments are not overwritten or reconstructed.

Installed copies can check and download updates from GitHub or the verified CNB mirror. Automatic checks remain off by default. Update metadata is project-signed; Setup still has no Windows Authenticode signature.
