# SteamWrapper 0.2.5 preview 1

Manager now offers **Check for updates**. Installed copies can download a verified update, close normally, run the existing per-user installer, and reopen Manager. Automatic checks are optional and off by default; portable copies keep the download-and-extract workflow.

- Updates come from the official GitHub repository, with CNB available when matching mirror files have been published. Automatic source selection can retry a network failure through an advertised mirror.
- A project-owned signing key authenticates the update information and exact installer bytes. This does not require a Windows code-signing certificate; Setup and the project's Windows binaries remain unsigned and Windows may show trust prompts or apply local restrictions.
- English and Simplified Chinese update messages cover progress, cancellation, unavailable sources, and verification failures. Update settings preserve existing preferences.
- Installing an update preserves game profiles, the stable Runner, Steam Launch Options, and game files. Other open Manager windows must close normally; no process is force-closed.
- First installation can choose an empty directory on a fixed local drive; updates and repairs stay at the registered location. Start menu shortcuts default on, desktop shortcuts default off, and setup offers opening Manager after completion. Changing location requires uninstalling Manager while keeping data, then reinstalling.
- Uninstall defaults to removing only Manager, its shortcuts and registration. Seven separate optional choices remove recognized SteamWrapper Launch Options, downloaded caches, logs, preferences, profiles, profile backups or verified Runner files. Steam must exit normally before option restoration or profile/Runner removal; unresolved Runner references prevent the latter. Standard commands are backed up and cleared, while custom commands remain unchanged. Unknown historical arguments cannot be reconstructed.
- Cleanup preserves Steam restoration backups, update trust state, unknown/busy files, games and saves. No application is force-closed to complete cleanup.

This is a technical preview. Clean Windows client acceptance and broader recovery tests remain separate gates. Earlier releases without the update interface need one manual installation of this version before using application updates. A published update feed advertises only a verified available release; a merge by itself does not publish software.
