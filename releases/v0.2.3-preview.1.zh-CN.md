# SteamWrapper v0.2.3-preview.1

这是用于测试和待提交 SignPath Foundation 申请的**未签名 Windows 技术预览**，支持原生 x64 电脑上的 Windows 11 24H2 或更高版本。干净客户端验收和生产签名仍未完成，不是稳定版。

- 没有已保存的语言选择时，Manager 及其独立启动器的恢复提示跟随已支持的系统界面语言。简体中文系统使用中文，不支持的语言使用英语。手动选择优先，不翻译游戏名称、路径、参数或诊断内容。
- 安装前的磁盘预算包含完整暂存载荷、清单、启动器副本与事务文件。隔离进程停止测试验证持久化恢复和租约释放，不终止已有 Manager 或游戏。
- 版本标签发布明确的第 2 版安装器与便携包结构，旧第 1 版便携描述单独保留。`SHA256SUMS` 列出其余六个附件的校验值，下载核验检查完整的七个附件。常规 main／PR CI 仍只测试和编译应用。
- 两种发行包都包含 `THIRD_PARTY_NOTICES.md`、`LICENSES/index.json` 哈希清单及依赖的原始许可证和声明，保留上游签名与许可条款。Microsoft 运行时／包条款仍需 Foundation 审核是否适用 System Libraries 例外，本项目的 Apache-2.0 许可证不会替代依赖自身的许可证。

使用 Setup 为当前用户安装 Manager，或解压**完整**便携 ZIP，在文件资源管理器中打开 `SteamWrapper.Manager.exe`。安装／卸载保留配置、偏好、稳定 Runner、备份、日志与缓存封面，不改变 Steam／游戏文件或启动选项。试用前阅读[安装与恢复指南](https://yangyus8.top/SteamWrapper/zh-cn/guides/installer-preview/)。载荷变化需要新的数字基础版本，不要用另一构建替换同版本内容。

已知限制：尚未验证无开发工具的干净 Windows、完整键盘／输入法／缩放／剪贴板、旧版本清理、注册表／快捷方式故障恢复及真实已签名下载。尚无自动更新或自动应用／恢复 Steam 启动选项。缺失封面保留占位图，官方 CDN 补图仍需明确开启，默认关闭。

[代码签名政策（Code signing policy）](https://yangyus8.top/SteamWrapper/zh-cn/project/design/code-signing/)：Foundation 申请与批准仍待完成，此预览不提供签名证书或认证更新源。默认操作不上传配置、游戏文件或游戏库内容；可选官方封面请求需要用户选择开启。GitHub 为二进制发行渠道；CNB 二进制仅在配置镜像并通过下载核验后可用。
