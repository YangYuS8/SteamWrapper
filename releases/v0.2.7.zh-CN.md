# SteamWrapper v0.2.7

首个采用 WinUI 3 管理器的 Windows 稳定版本。配置一次游戏，将生成的启动选项复制到 Steam，此后即可正常从 Steam 启动。日常启动由独立 Runner 完成，不会打开管理器。

- Setup 按当前用户安装，可选择安装目录、开始菜单及桌面快捷方式，并选择完成后打开管理器。无需开发 SDK 或另行安装运行库。
- 应用完整支持英语和简体中文。未保存语言选择时，界面跟随受支持的 Windows 界面语言，否则使用英语。
- 封面默认离线工作，优先使用 Steam 本地图片。可选设置允许从官方 Steam CDN 补充缺失封面；无法显示的图片保留友好的占位图。
- 管理器支持手动检查更新，通过项目签名信息及精确安装包校验验证下载。GitHub 与经过验证的 CNB 镜像提供相同版本。自动检查默认关闭，安装会等待管理器正常退出。
- 更新和修复保留玩家数据，并保留上一管理器版本供恢复。卸载默认保留配置和稳定路径的 Runner，另提供七项独立可选清理选项。
- Runner 内含所需的 C/C++ 运行库。管理器会提示保存一个游戏配置即可更新可识别的旧 Runner，仅检查版本时不会替换它。
- 初始窗口尊重实际显示缩放和屏幕可用区域。稳定版本显示 Windows 版标识，开发及预览版本保留预览版标识。

Windows 发行包为 x64，最低需要 Windows 11 24H2，干净客户端验收使用 Windows 11 24H2。Windows 10、ARM64、Linux／SteamOS 管理器及通用的一键应用／恢复 Steam 启动选项不在本次范围内，Steam 启动选项仍需手动复制。便携版必须完整解压，更新时使用新的完整 ZIP。

Setup 和项目自有 Windows 程序未进行 Windows Authenticode 代码签名，系统可能显示信任提示或应用本机限制。项目签名的更新信息用于认证应用内更新的安装包，不提供 Windows 发布者证书。请使用官方下载及发布的校验和，并保持 Windows 防护开启。

SteamWrapper 不修改游戏二进制文件或存档，也不注入 DLL。第三方汉化版能否获得成就取决于游戏自身的 Steam 集成，SteamWrapper 无法保证。
