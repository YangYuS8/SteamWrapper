# SteamWrapper 0.2.5 预览版 1

管理器新增**检查更新**。安装版可以下载经过验证的更新，正常退出后使用现有每用户安装器安装，再重新打开管理器。自动检查可选且默认关闭；便携版继续采用下载后解压到新目录的方式。

- 更新来自官方 GitHub 仓库；CNB 发布了对应镜像文件后也可使用。自动选择来源时，可在网络失败后通过已公布的镜像重试。
- 更新信息及对应安装包由项目自己的签名密钥验证，不需要 Windows 代码签名证书。Setup 和项目自有 Windows 程序仍未进行 Windows 代码签名，系统可能显示信任提示或应用本机限制。
- 更新界面提供完整英文与简体中文，包含进度、取消、来源不可用及验证失败提示；更新设置保留原有偏好。
- 安装更新保留游戏配置、稳定路径中的 Runner、Steam 启动选项与游戏文件。其他管理器窗口需正常关闭，不会强制结束进程。
- 首次安装可选择本地固定磁盘上的空目录；升级和修复留在登记位置。开始菜单快捷方式默认开启、桌面快捷方式默认关闭，完成后可打开 Manager。换目录需要先卸载 Manager 并保留数据，再重新安装。
- 默认卸载只删除 Manager、快捷方式与注册项。七个独立可选项分别移除可识别的 SteamWrapper 启动选项、下载缓存、日志、偏好、配置、配置备份或经过验证的 Runner。还原启动项或删除配置／Runner 前需正常退出 Steam，残留 Runner 引用会阻止后两者删除。标准命令先备份再清空，自定义命令保持不变，不能重建未知的历史参数。
- 清理保留 Steam 恢复备份、更新信任状态、未知／占用文件、游戏及存档，不会为了完成清理而强制关闭应用。

当前仍为技术预览，干净 Windows 客户端验收和更广泛的恢复测试属于独立门槛。没有更新入口的旧版需要先手动安装本版，之后才能使用应用内更新。更新源只公布已经验证且可下载的版本；合并代码本身不会发布软件。
