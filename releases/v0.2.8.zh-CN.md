# v0.2.8

## 更新

- 游戏编辑界面新增**撤销编辑**、**恢复 Steam 启动**和**移除配置**。恢复启动保留配置；移除配置保留备份，不删除游戏或存档。
- 游戏列表使用 Steam 本地缓存中对应界面语言的官方名称，保留自定义名称和未保存的编辑，无需联网查询商店。
- 应用标题精简为 **SteamWrapper**，版本号单独显示。
- 公开下载只保留安装器、便携 ZIP 和校验和。GitHub 发布日志只用英语，CNB 只用简体中文。
- Actions 跳过无关检查，复用固定工具／依赖缓存，每项 Rust 进程回归只运行一次；版本发布仍保留完整门禁。

## 安装与更新

Setup 提供安装目录和快捷方式选项；便携版需完整解压 ZIP。支持范围仍为 Windows 11 24H2 x64，请使用平时运行 Steam 的 Windows 账户。

恢复 Steam 启动或移除配置前，请正常退出 Steam。只清除精确匹配的标准命令，不覆盖自定义启动项，也不会猜测或重建未知的旧参数。

安装版可从 GitHub 或已核验的 CNB 镜像检查和下载更新。自动检查默认关闭。更新信息使用项目签名；Setup 仍无 Windows Authenticode 签名。
