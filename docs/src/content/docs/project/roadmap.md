## Direction

Keep the Windows-first product boundary: configure a game in the WinUI 3/C# Manager, then launch it through Steam's independent Rust Runner. C# configuration services, TOML, stable data paths and CLI remain the foundation. The next priorities are **player feedback → Windows delivery and releases → optional updates and safe Steam integration → later platform expansion**.

**Merging v2 into main alone does not publish a stable product release.** The current scoped delivery gates are summarized below. As of **2026-10-02**, WinUI is the only Manager: the Dioxus app, Rust `manager-core`, Dioxus Native E2E and old UI release chain have been removed at the user's request. This changes the supported implementation; it does not mark unfinished Windows delivery gates as passed. The [Windows v2 design](/SteamWrapper/project/design/windows-v2/) records the architecture and original stages; the [WinUI assessment](/SteamWrapper/project/decisions/winui3/) records the technical basis. The milestones below set acceptance order without promising dates or reinterpreting published version numbers. See [preview validation](/SteamWrapper/project/validation/winui/) for scoped evidence.

**Version rule for the current deployment contract:** every new installable payload/manifest needs a new coordinated `MAJOR.MINOR.PATCH`. Changing only a preview suffix retains the numeric version, so installation correctly rejects same-version/different-content. The latest public release is stable `v0.2.7`. The earlier private 0.2.7 test payload is not interchangeable with the public package. Retry the exact immutable artifact; do not rewrite a public tag or weaken the version gate. This rule applies regardless of Authenticode signing.

**Retention compatibility:** the frozen `0.2.1`/`0.2.2` deployment implementations reject unknown installation-root files and JSON fields. **Historical defect, before the readiness change:** uninstall accepted at most 32 retained versions while installation neither pruned nor bounded admission, so a long upgrade sequence could block uninstall.
