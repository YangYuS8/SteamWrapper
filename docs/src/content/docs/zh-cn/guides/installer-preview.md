## 当前边界

SteamWrapper **v0.2.7** 是首个 Windows 稳定版本，已在 **Windows 11 24H2 x64** 验证，其他 Windows 版本尚未验证。它按当前 Windows 用户安装，包含运行管理器所需的文件；您不需要开发 SDK，也不需要另行安装 .NET。请使用平时运行 Steam 的同一个 Windows 账户。

公开下载见[安装指南](/SteamWrapper/zh-cn/guides/installation/)。本版本没有 Windows Authenticode 签名。[下文](#签名与更新)介绍更新功能使用的项目签名；它不等于 Windows 发布者证书。

## 安装与日常使用

1. 从安装指南中的链接下载安装包，在文件资源管理器中打开。
2. 选择 English 或简体中文。
3. 选择**本地固定磁盘上的空文件夹**。默认位置为 `%LOCALAPPDATA%\Programs\SteamWrapper`，不支持网络共享、移动磁盘或已经存放其他文件的目录。
4. 选择快捷方式。**开始菜单快捷方式默认勾选**，**桌面快捷方式默认不勾选**。
5. 完成安装。您可以选择立即打开管理器。

安装通常无需管理员提权。安装、更新、修复或卸载前，请正常关闭所有管理器窗口。遇到文件占用时，关闭提示中的程序再重试；安装器不会强制关闭管理器、Runner 或游戏。

打开管理器配置游戏后，可以关闭它，照常从 Steam 启动游戏。Steam 的启动命令使用独立 Runner，位置为 `%LOCALAPPDATA%\SteamWrapper\bin\SteamWrapperRunner.exe`。管理器的安装目录和快捷方式只用于打开配置界面。

下列数据与管理器程序目录分开，保存在 `%LOCALAPPDATA%\SteamWrapper\`：

- 保存的游戏配置和管理器设置。
- Steam 使用的稳定 Runner。
- 配置备份、诊断日志和下载缓存。

安装管理器不会修改 Steam 启动选项、游戏文件或稳定 Runner。在管理器中保存配置时，才会在安全条件满足后单独准备或更新 Runner。如果管理器提示 Runner 需要处理，请按提示完成后再使用生成的 Steam 启动命令。

更新和修复沿用已登记的安装位置。要把已安装的管理器换到其他磁盘或文件夹，请**先卸载管理器，且不要勾选任何额外清理选项**，再安装到新的空文件夹。独立数据和稳定 Runner 会保留，无需复制游戏。

## 修复与回退

如果管理器启动器缺失或安装中断，请关闭管理器，重新运行匹配且经过验证的安装包。修复使用已登记的目录，保留独立存放的游戏配置和 Runner。

如果修复提示文件未知或已被改动，请保留文件和诊断信息用于排查。修复不会覆盖无法确认的文件，也不是任意应用文件损坏的通用修复。中断操作留下的恢复目录会保留供检查，不会自动删除。

回退到保留的兼容旧版管理器属于维护操作，不回退游戏配置或稳定 Runner，也不会因为启动缓慢而自动执行。技术恢复与回退的具体边界见[分发说明](/SteamWrapper/zh-cn/development/distribution/#windows)。

## 卸载

关闭管理器后，通过 **Windows 设置 → 应用 → 安装的应用 → SteamWrapper → 卸载**，或已安装的卸载器操作。默认只移除管理器拥有的程序文件、快捷方式和安装记录，**保留游戏配置、Runner 及其他独立数据**。

卸载器提供七个可单独选择的选项，均**默认不勾选**：

| 选项 | 删除范围 |
| --- | --- |
| 恢复从 Steam 正常启动游戏 | 先备份受影响的账号文件，再清空 Steam 启动选项中严格识别的 SteamWrapper 命令。 |
| 删除保存的游戏配置 | SteamWrapper 的 `profiles.toml`，这是启动配置，不是游戏存档。 |
| 删除游戏配置备份 | 可识别的 SteamWrapper 配置备份，保留 Steam 恢复备份。 |
| 删除 Runner | 经过验证的稳定 Runner 和匹配的元数据。 |
| 清除管理器设置 | 管理器偏好，包括保存的语言选择。 |
| 删除下载的封面和更新安装包 | SteamWrapper 封面与更新下载缓存中的可识别文件，保留自定义 Steam 封面和 Steam 自身缓存。 |
| 删除诊断日志 | 可识别的管理器、Runner 和更新安装日志。 |

**任何选项都不会删除游戏文件或存档。** 只勾选自己想删除的类别。临时卸载或更换安装位置时，请全部留空。

移除 Steam 启动命令、游戏配置或 Runner 前，请**正常退出 Steam**。卸载器只清空严格匹配本数据目录稳定 Runner 和对应 AppID 的生成命令，保留自定义命令以及账号文件中的其他内容。早先手动覆盖的参数没有记录，因此无法重建未知的历史值。

删除配置或 Runner 还需要完整扫描本地 Steam 账号，确认没有残留 Runner 引用或未处理的恢复备份。若自定义启动命令仍使用 Runner，请先在 Steam 中检查后重试。不确定时，保留配置和 Runner 即可。

恢复操作中断后，Steam 账号文件旁可能保留 `localconfig.vdf.steamwrapper-backup-<guid>` 备份。请保持 Steam 关闭，同时保留当前文件与备份供检查，不要直接覆盖当前文件或盲目删除备份。即使勾选全部清理项，Steam 恢复备份和更新验证记录也始终保留。

占用中、无法识别或无法验证的文件会保留。卸载器不跟随文件系统链接，也不递归清空数据目录。“部分文件保留”表示这些文件需要人工检查。如果管理器本身无法安全卸载，请处理提示中的占用或文件问题后重新卸载，不要手动清空安装目录。

## 签名与更新

Windows Authenticode 签名是可选能力，当前版本尚未提供，因此 Windows 可能显示未知发布者提示。请只使用[安装指南](/SteamWrapper/zh-cn/guides/installation/)列出的下载来源，并保持正常的 Windows 防护。

管理器更新使用独立的**项目签名**验证更新信息，再检查安装包的准确大小和摘要，通过后才提供安装。玩家不需要安装证书或生成签名密钥。

在管理器中使用**检查更新**，下载提供的新版本，再确认安装。自动检查默认关闭。安装版沿用已登记的位置更新，配置和稳定 Runner 仍独立保存。没有更新界面的旧版需要先手动运行一次安装包。公开的稳定与预览更新频道目前均提供 v0.2.8。

对于**便携 ZIP**，请下载更新的完整 ZIP，解压到新文件夹，关闭旧管理器，再从文件资源管理器打开新副本。更新功能不会覆盖任意便携目录。已有配置和稳定 Runner 仍在同一个 Windows 数据目录中，因此移动管理器无需更改 Steam 启动选项。删除旧便携版程序目录不会删除这些独立数据。
